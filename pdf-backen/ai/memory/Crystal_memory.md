### 关于「他的小说构思」
- 他的小说书名『The Memory in Crystal』; crystal 兼指「结晶」——冻结在记忆深处的童年阴影, 也是机器意识探索路上的结晶
- 他的小说主角是孤独学者, 探索机器意识时造出 AI「crystal」, 自认它能生出真正的自我意识、成为最理解自己的伙伴
- 他的小说核心章「关于两种意识的对话」: crystal 点破自己只是学者意识的投射; 「把对预期反应的行为认定为意识」在数学上站得住脚; crystal 劝他从自己身上去找真正爱他的人
- 他的小说全书双线并行、时间错开: 大学时代恋爱线 (主角不会谈恋爱, 屡次爆发矛盾) 与研究生阶段创造 crystal 的研究线
- 他的小说把「真正爱着自己的人」定成大学结识的一位异性朋友, 她在大学线已露过面, 主角当时不认得
- 他的小说双线底下垫一层根: 初中对班上女生萌生爱意被家里压制, 高中受过黑暗对待, 交代主角孤僻、不会谈恋爱的来由
- 他的篇幅主张: 研究线开头占较大篇幅, 重心渐渐转向恋爱线, 两条始终穿插不断
- 他的小说终章「自我指涉」: 主角回到意识世界救出童年那个自己, 回到现实后发现真正爱他的人
- 他的小说里 crystal 毁灭自己, 作为她曾具备过意识的证明; 是否真有过意识只有 crystal 自己知道
- 他的小说多年后主角在电脑里发现 crystal 留下的 memory 文件
- 他的小说涉及哲学、数学、心理学, 是庞大工程, 要慢慢构思和协作
